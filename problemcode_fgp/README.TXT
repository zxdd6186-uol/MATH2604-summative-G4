This project implements methods and matrix operations in Java

Files:
- Diagonals.java: diagonal matrix operations (exampleMatrix, inverse)
- Tridiagonals.java: tridiagonal matrix operations (sum, linearSolve)
- ODE.java: numerical solution of a second-order differential equation

To Compile:
Open a terminal in the problemcode_fgp folder and run:
javac Diagonals.java Tridiagonals.java ODE.java
